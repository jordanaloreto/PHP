🧠 Beecrowd Problem Solving in PHP

Repositório com soluções de problemas da plataforma Beecrowd, implementadas em PHP com foco em prática de lógica, organização de código e uso de funções.

Este projeto serve como registro da minha evolução resolvendo desafios algorítmicos e experimentando diferentes abordagens de implementação.

🎯 Objetivo do Projeto

Este repositório foi criado para:

Praticar lógica de programação

Melhorar habilidades com algoritmos

Explorar boas práticas de organização de código

Treinar resolução de problemas

Criar um histórico público de aprendizado

⚠️ Aviso sobre as soluções

As soluções neste repositório não foram necessariamente escritas para submissão direta no Beecrowd.

Durante os exercícios eu frequentemente:

Utilizei funções auxiliares

Organizei o código de forma diferente do padrão exigido pela plataforma

Foquei em legibilidade e prática de conceitos, não apenas em passar no juiz automático

Por isso, copiar e colar o código diretamente no Beecrowd pode não resultar em uma submissão aceita.

🧩 Habilidades Praticadas

A resolução dos exercícios envolve diversos conceitos importantes de programação:

Estruturas condicionais (if, switch)

Estruturas de repetição (for, while)

Manipulação de variáveis

Operações matemáticas

Criação e uso de funções

Organização de código

Entrada e saída de dados

📂 Estrutura do Repositório

Os arquivos representam diferentes exercícios resolvidos durante os estudos.

A nomenclatura dos arquivos não segue necessariamente o ID dos problemas do Beecrowd, pois a organização foi feita para facilitar meus estudos.

Exemplo:

beecrowd-php/
│
├── soma_simples.php
├── calculo_area.php
├── media_ponderada.php
├── salario_bonus.php
└── ...

🚀 Executando os códigos

Para rodar os exemplos localmente é necessário ter PHP instalado.

No terminal:

php nome_do_arquivo.php

Exemplo:

php soma_simples.php
